# Changelog

All notable user-visible changes to the Omni Tools TOS application package.

## 0.7.0-1 — 2026-11-15

### Added
- First release. Omni Tools (`iib0011/omni-tools:0.7.0`, Docker Hub official image, unmodified)
  packaged as a TOS 7 Docker application, published on port 8164 and running
  as a non-root user (1000:1000).
- Persistent data is kept under `/Volume1/DockerAppData/omnitoolsdocker/`.
